# IDC v3.0 技术变更记录

更新时间：2026-05-22

本文记录当前工程相对早期版本的主要控制逻辑变更、实车调参入口和已知待调事项。当前工程入口仍为 `IDC/Project/IDC_project.uvprojx`。

## 1. 自动巡线流程

文件：`IDC/USER/main.c`

当前 PE0 按键启动后的状态机为：

```text
State 0: 待机
State 1: 正向巡线 15s
State 2: 原地转 180 度，约 1.5s
State 3: 反向巡线 1.5s
State 0: 回到待机
```

当前参数：

```c
#define TURN_ERPM                   3000
#define LINEFOLLOW_FORWARD_TIME_US  15000000U
#define LINEFOLLOW_TURN_TIME_US     1500000U
#define LINEFOLLOW_REVERSE_TIME_US  1500000U
```

注意事项：

- 正向巡线的前进方向已经修正，基础速度方向由 `LINEFOLLOW_FORWARD_SIGN` 控制。
- 反向巡线时间已从 15s 改为 1.5s。
- State 2 原地转向期间会临时关闭 `LineFollow_Enabled`，但 `DEBUG_LineFollowState` 仍为 2。

## 2. 巡线控制参数

文件：`IDC/HARDWARE/LINE_FOLLOW/line_follow.c`

当前巡线参数参考了 `IDC4.0(1)` 中更好用的一版：

```c
#define LINEFOLLOW_BASE_ERPM_MAX         12000
#define LINEFOLLOW_STEER_MAX_ERPM        9000
#define LINEFOLLOW_LOST_STEER_ERPM       6000
#define LINEFOLLOW_OUTPUT_ERPM_MAX       16000
#define LINEFOLLOW_FORWARD_SIGN          (-1)
#define LINEFOLLOW_KP_NUM                10
#define LINEFOLLOW_KP_DEN                1
#define LINEFOLLOW_KD_NUM                4
#define LINEFOLLOW_KD_DEN                1
```

含义：

- `LINEFOLLOW_BASE_ERPM_MAX`：巡线基础速度上限。
- `LINEFOLLOW_STEER_MAX_ERPM`：转向修正最大幅度。
- `LINEFOLLOW_LOST_STEER_ERPM`：丢线后按上一次偏差方向找线的转向幅度。
- `LINEFOLLOW_OUTPUT_ERPM_MAX`：巡线最终左右轮输出限幅。
- `LINEFOLLOW_FORWARD_SIGN`：巡线正向前进方向。当前为 `-1`。
- `LINEFOLLOW_KP_NUM` / `LINEFOLLOW_KD_NUM`：巡线 PD 参数。当前响应较激进，若实车左右摆动明显，优先降低 `KP` 到 8 左右。

## 3. 遥控速度与停车锁轴

文件：`IDC/HARDWARE/ACTUATOR/actuator.c`

遥控最大速度：

```c
#define VESC_MAX_ERPM 25000
```

停车锁轴已加入，底层使用 VESC 的 `SET_CURRENT_BRAKE`：

```c
#define VESC_BRAKE_HOLD_DELAY_US       200000U
#define VESC_BRAKE_HOLD_CURRENT_MA     1000
#define VESC_BRAKE_HOLD_STEP_MA        100
```

行为：

- 左右轮命令都为 0，且未处于巡线使能时，先等待 200ms。
- 然后刹车电流每 10ms 增加 100mA，最高到 1000mA。
- 一旦收到运动命令，立即退出锁轴并恢复 RPM 控制。

VESC CAN 新增接口：

```c
void VescCan_SetBrakeCurrent(uint8_t controller_id, int32_t current_mA);
```

注意事项：

- `VESC_BRAKE_HOLD_CURRENT_MA` 不宜一开始设太大，过大会导致停车抽动、发热或啸叫。
- VESC Tool 中的 `Motor Current Max Brake` 和 `Battery Current Max Regen` 会限制实际刹车效果。

## 4. 夹爪控制逻辑

文件：`IDC/HARDWARE/ACTUATOR/actuator.c`

当前夹爪 PWM 参数：

```c
#define SERVO_PULSE_MIN_US      500U
#define SERVO_PULSE_MAX_US      2500U
#define SERVO_OPEN_US           1500U
#define SERVO_START_OPEN_US     SERVO_PULSE_MAX_US
#define SERVO_TENNIS_US         2278U
#define SERVO_GOLF_US           1944U
```

当前逻辑：

- 上电后，在第一次收到 CH4 有效夹爪信号前，夹爪保持 `SERVO_START_OPEN_US`。
- 进入自动巡线流程后，只要 `DEBUG_LineFollowState != 0U` 或 `LineFollow_IsEnabled() != 0U`，夹爪强制保持 `SERVO_START_OPEN_US`，不会被 CH4 三档控制覆盖。
- 巡线结束后，恢复 CH4 三档控制。

CH4 三档控制：

```text
CH4 高位 -> SERVO_TENNIS_US
CH4 低位 -> SERVO_GOLF_US
CH4 中位 -> SERVO_OPEN_US
```

重要待调事项：

- 当前夹爪实测还不能张到 180 度，说明 `SERVO_START_OPEN_US` / `SERVO_PULSE_MAX_US` 或机构安装角度仍需调整。
- 当前最大张开使用 `2500us`。如果舵机安全范围允许但仍不到 180 度，需要检查：
  - 舵机本体是否支持 180 度行程。
  - 机械连杆是否提前限位。
  - `SERVO_PULSE_MAX_US` 是否需要继续增大，必须小步测试，例如每次增加 50us。
  - 若 `2500us` 反而是夹紧方向，应改用 `SERVO_PULSE_MIN_US` 作为最大张开方向。
- 不建议一次大幅增加脉宽，避免舵机顶死发热。

## 5. 步进电机升降与微调

文件：`IDC/HARDWARE/ACTUATOR/actuator.c`

当前 EMM5 参数：

```c
#define EMM5_LIFT_SPEED_RPM     300U
#define EMM5_LIFT_ACCEL         50U
#define EMM5_LIFT_POS_LOW       0U
#define EMM5_LIFT_POS_HIGH      5000U
#define EMM5_LIFT_POS_MAX       7000U
#define EMM5_LIFT_TRIM_STEP     300U
```

当前逻辑参考 `IDC4.0(1)`：

- CH5 用于大位置切换：
  - 高位：移动到 `EMM5_LIFT_POS_HIGH`
  - 低位：移动到 `EMM5_LIFT_POS_LOW`
- CH3 用于微调：
  - 从中位拨到一侧，只触发一次微调。
  - 保持在同一侧不会连续运动。
  - 回中后再拨同一侧，可以再次微调。
  - 回中时关闭 EMM5 使能，并清零 `Act_LiftMode` / `Act_LiftSpeed`。

调试变量：

```c
volatile uint32_t Act_LiftTargetPulse;
volatile uint16_t Act_LiftPulseCount;
volatile uint32_t Act_LiftTriggerCount;
```

如果单次微调幅度过大，将 `EMM5_LIFT_TRIM_STEP` 从 `300U` 降到 `100U` 或 `150U`。

## 6. 需要重点实车确认

1. 夹爪最大张角
   - 当前还不能张到 180 度。
   - 优先调 `SERVO_START_OPEN_US` / `SERVO_PULSE_MAX_US`，并确认机械结构没有限位。

2. 巡线稳定性
   - 当前 `KP=10`、`KD=4`、转向上限 `9000`，属于较强响应。
   - 若高速下摆动，优先降低 `LINEFOLLOW_KP_NUM`。

3. 停车锁轴
   - 当前保持电流 `1000mA`。
   - 若停车抽动，降低到 `500mA` 或增加 `VESC_BRAKE_HOLD_DELAY_US`。
   - 若锁不住，逐步提高到 `1200mA` / `1500mA`，同时观察电机和电调温度。

4. 步进微调方向
   - 如果 CH3 上下方向与预期相反，交换微调分支中的加减方向即可。
