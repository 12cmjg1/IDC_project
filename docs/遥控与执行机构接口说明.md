# 遥控输入与执行机构接口说明

本文档说明当前 `STM32F407VET6 C30D-V2.0` 遥控测试工程的接线、控制规则、调试变量和当前已知限制。

当前版本已经去掉对 `DWT->CYCCNT` 的运行依赖，改为使用 `TIM10` 作为独立微秒时间基准。目标是让板子在普通复位后也能直接进入遥控运行状态，不再要求先进入一次 Debug。

在此基础上，当前工程又加入了一套独立的 **CCD 巡线模式**：

- 用用户按键 `PE0` 作为巡线模式开关
- 巡线模式开启后，左右轮由 CCD 自动控制
- `CH3` 继续控制巡线速度大小
- `CH5` 和 `CH6` 仍继续控制夹爪和丝杆

## 1. 目标

当前工程接收 HT-6A 2.4G 接收机的 6 路标准 PWM 信号，并将其中一部分映射到：

- 左后轮电机
- 右后轮电机
- 丝杆升降步进电机
- 夹爪舵机

接收机 PWM 规格默认按以下范围处理：

- 周期：约 `20 ms`
- 有效高电平脉宽：`800 us ~ 2200 us`
- 中位：约 `1500 us`

## 2. 接收机接线

接收机所有通道共用一组电源，不需要每个通道都单独接 `+` 和 `-`。

| 接收机 | STM32 引脚 | 作用 |
| --- | --- | --- |
| CH1 S | PA2 | `RC_CH[0]`，原地旋转 |
| CH2 S | PA3 | `RC_CH[1]`，前进 / 后退 |
| CH3 S | PA6 | `RC_CH[2]`，速度大小 |
| CH4 S | PA7 | `RC_CH[3]`，预留 |
| CH5 S | PA8 | `RC_CH[4]`，夹爪控制 |
| CH6 S | PC0 | `RC_CH[5]`，丝杆触发 |
| 任意 `+` | 3V3 | 接收机供电 |
| 任意 `-` | GND | 公共地 |

注意：

- 接收机地线必须和 STM32 地线共地。
- 如果某一路始终没有变化，先查信号线、共地和对频状态，不要先怀疑执行机构逻辑。

## 3. 执行机构接线

| 输出 | STM32 引脚 | 信号类型 | 作用 |
| --- | --- | --- | --- |
| CAN1 RX | PD0 | CAN1 | 接收 VESC / EMM5 的 CAN 数据 |
| CAN1 TX | PD1 | CAN1 | 发送 VESC / EMM5 的 CAN 数据 |
| 夹爪舵机 | PC6 | TIM3_CH1 | 50Hz 舵机 PWM |
| 调试串口 TX | PA9 | USART1_TX | `printf` 输出 |
| 调试串口 RX | PA10 | USART1_RX | 可选串口输入 |

说明：

- 当前板内 CAN 走 `PD0 / PD1`。
- 如果 C30D 板外部给的是 `CANH / CANL`，那是板上收发电路后的总线口，外部接线应接那个口。

## 3.1 巡线 CCD 与用户按键接线

| 信号 | STM32 引脚 | 作用 |
| --- | --- | --- |
| CCD AO | PA4 | CCD 模拟输入 |
| CCD CLK | PA5 | CCD 时钟输出 |
| CCD SI | PC4 | CCD 启动脉冲 |
| 用户按键 | PE0 | 巡线模式开关 |

说明：

- 这部分接法参考了旧工程里的巡线方案。
- 当前只接入 CCD 巡线，不再使用旧的 `PC0~PC3` 四路红外巡线输入。
- `PC0` 仍然保留给 `CH6`，不和巡线冲突。

## 4. 通道控制规则

| 通道 | 规则 |
| --- | --- |
| CH1 | 右手左右，控制原地旋转。只有离开中间死区后才开始转。 |
| CH2 | 右手前后，控制前进和后退。高于中位前进，低于中位后退。 |
| CH3 | 左手前后，控制速度大小。最下方为 0，最上方为最大，线性变化。 |
| CH4 | 已采集，当前未使用。 |
| CH5 | 三挡夹爪控制。中间打开，上方夹网球，下方夹高尔夫球。 |
| CH4 | 左手左右，丝杆微调。向左微微下降，向右微微上升。 |
| CH6 | 丝杆固定高度切换。拨上到高位，拨下到低位。 |

当前临时逻辑：

- 当 `CH1` 超出中间死区时，小车执行原地旋转，此时忽略 `CH2`。
- 当 `CH1` 回到中间死区时，`CH2` 控制直行前进和后退。
- `CH3` 始终作为速度倍率，对直行和原地旋转都生效。
- 当前手动左右转向方向已做一次反向修正。
- 当前手动直行最高速度已从 `12000 ERPM` 上调到 `14000 ERPM`。
- `CH5` 只使用三个固定位置：打开、网球位、高尔夫球位。
- `CH6` 不再是“打一小段”的模式，而是直接切到两个固定高度之一。
- 当前固定高度默认值：
  - 低位：`0`
  - 高位：`5000`
- `CH4` 负责丝杆微调：
  - 向左：每次微微下降
  - 向右：每次微微上升
- 当前每次微调默认步长：`100`

### 4.1 巡线模式规则

- 用户按下 `PE0` 一次：进入巡线模式
- 再按一次：退出巡线模式
- 巡线模式打开后：
  - 左右轮不再直接使用 `CH1`、`CH2`
  - 左右轮改由 CCD 自动控制
  - `CH3` 继续控制巡线速度大小
  - `CH5`、`CH6` 保持原功能
- 巡线模式关闭后：
  - 恢复普通遥控模式

死区规则：

- 输入在 `1500 us` 附近约 `±40 us` 时，按 0 处理。

有效范围：

- 低于 `800 us` 或高于 `2200 us` 的输入，不作为有效脉宽处理。

## 5. 当前 CAN 规则

### 5.1 左右轮 VESC

- CAN 波特率：`500 kbps`
- CAN 引脚：`PD0 = CAN1_RX`，`PD1 = CAN1_TX`
- 左电调 ID：`1`
- 右电调 ID：`2`
- 左轮方向：当前代码已做一次反向修正
- 命令类型：VESC `SET_RPM`
- 帧类型：扩展帧
- 发送周期：约 `10 ms`

当前左右轮发包格式：

```text
ExtId = (3 << 8) | vesc_id
DLC   = 8
Data[0..3] = 有符号 ERPM，按高字节在前发送
Data[4..7] = 0
```

### 5.2 丝杆 EMM5

- 驱动类型：`EMM5`
- 节点 ID：`3`
- 命令类型：扩展 CAN 分包命令
- 当前每次动作：`200` 脉冲

当前已知限制：

- 左右轮这条 VESC CAN 路径，已经按现有 VESC 客户资料整理，适合直接联调。
- 丝杆这条 EMM5 CAN 路径，现已改成参考 `try_can_control` 里能跑通的版本。
- 发送方式不是普通 `StdId=地址` 的单帧，而是扩展 ID 分包发送。
- 每个分包都会重复带命令码，后面再带本包的数据。
- 当前 `CH6` 触发后，会直接切到预设绝对高度。
- 当前 `CH4` 触发后，会在当前高度基础上做小步微调。
- 这意味着：如果 `RC_CH[5]`、`RC_CH[3]`、`Act_LiftMode`、`Act_LiftTriggerCount` 都在变化，而丝杆仍不动，重点应该查丝杆驱动器本体、供电和总线接线。

这些变量里最关键的含义：

```text
Act_LeftMotor / Act_RightMotor
    已经从遥控量计算出来的左右轮目标值。

VescCan_TxCount
    只表示程序尝试排队发送了一次 CAN。
    它不能证明这一帧真的发到了总线上，也不能证明电调已经收到。

VescCan_TxOkCount / VescCan_TxFailCount / VescCan_TxNoMailboxCount
    用来区分“发送成功”“发送失败”“发送邮箱不够”。

VescCan_LastMailbox
    最近一次发送时，STM32 CAN 外设返回的邮箱结果。
    排查发送异常时，要和 VescCan_TxCount 一起看。

VescCan_LastTxStatus
    最近一次发送状态。
    常见判断：
    0 = 还在等待
    1 = 发送成功
    2 = 发送失败
    255 = 连发送邮箱都没拿到

VescCan_RxCount
    进入 CAN 接收 FIFO0 的总帧数。

VescCan_LastESR / VescCan_LastMSR / VescCan_LastTSR
    这是 CAN 外设当前状态快照。
    主要在需要深挖时使用。

VescCan_LastErrorCode
    最近一次总线错误码。

VescCan_BusOff / VescCan_ErrorPassive / VescCan_ErrorWarning
    分别表示：总线关闭、错误被动、错误预警。
    这几个量一旦非 0，优先查总线接线和波特率。

VescCan_RxFifo0Pending
    当前接收 FIFO0 里还有多少帧待取出。

VescCan_LeftStatusSeen / VescCan_RightStatusSeen
    只要对应电调成功回过至少一次有效状态帧，就会变成 1。

VescCan_LeftStatusErpm / VescCan_RightStatusErpm
    电调真正回报的 ERPM。

LineFollow_Enabled
    0 表示普通遥控模式，1 表示 CCD 巡线模式。

LineFollow_Position
    当前线中心位置，范围约为 -1000 到 +1000。

LineFollow_Width
    当前识别到的黑线宽度。

LineFollow_Cross
    1 表示当前识别到较宽的横线或十字区域。

LineFollow_Lost
    1 表示当前丢线。

LineFollow_LeftCmdErpm / LineFollow_RightCmdErpm
    巡线模式下计算出来的左右轮目标值。
```

## 12. 基本联调步骤

1. 用 ST-Link 编译并下载程序。
2. 进入 Debug 后点击 `Run`。
3. 先看 `DEBUG_AliveCount`，确认程序在持续运行。
4. 再看 `RC_CH_EdgeCount[0]` 到 `RC_CH_EdgeCount[5]`，确认每一路接收机输入都在跳动。
5. 再看 `RC_CH[0]` 到 `RC_CH[5]`，确认摇杆动作会落到约 `1000 us ~ 2000 us`。
6. 加入 `Act_LeftMotor`、`Act_RightMotor`、`VescCan_TxCount`、`VescCan_RxCount`、`VescCan_LeftStatusSeen`、`VescCan_RightStatusSeen`。
7. 如果准备试巡线，再加入 `LineFollow_Enabled`、`LineFollow_Position`、`LineFollow_Width`、`LineFollow_LeftCmdErpm`、`LineFollow_RightCmdErpm`。
8. 再加入 `VescCan_TxOkCount`、`VescCan_TxFailCount`、`VescCan_TxNoMailboxCount`、`VescCan_BusOff`、`VescCan_LastErrorCode`。
9. 先确认左右轮目标值会随摇杆变化，再看发送状态是否正常。
10. 巡线模式下按一次 `PE0`，确认 `LineFollow_Enabled` 变为 `1`。
11. 如果 `VescCan_TxCount` 在增加，但 `VescCan_TxOkCount` 不增加，优先排查发送链路本身。
12. 如果 `VescCan_TxOkCount` 在增加，但 `VescCan_RxCount` 和左右 `...StatusSeen` 一直不变，优先排查接线、波特率、ID 和电调配置。
13. 第一次测电机时，车轮要架空，或者先断开动力侧，只看控制链路。

## 13. 安全规则

- 不要从电机驱动输出口给接收机供电。
- 不要把电机电源直接接到 STM32 或接收机信号脚。
- STM32 GND、接收机 GND、电调逻辑地、步进驱动地、舵机地必须共地。
- 先确认 PWM 输入稳定，再接电机。
- 第一次试车时，轮子必须离地。
- 在执行机构动作前，先看清楚 CH1 到 CH6 的值是否正常。
- 如果某一路一直是 0，先查接线、对频、共地，再查程序。
- **不要把 `VescCan_TxCount` 当成“电调一定收到”的证据。**
- 如果 `VescCan_BusOff`、`VescCan_ErrorPassive`、`VescCan_ErrorWarning` 有任何一个不为 0，先停下来查总线，不要继续怀疑遥控逻辑。
- 丝杆 EMM5 的 CAN 命令路径目前仍是“可编译、可联调、待真机确认”的状态。
